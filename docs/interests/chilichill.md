# Chilichill
Chilichill 的早期音乐多为洛天依演唱，现在的新歌由夏老师来唱。调高的可怕，吓哭了。

很喜欢 Chilichill 的曲风。慵懒、自由，好像世界与我无关。明艳、鲜活，又好似世界与我息息相关。
