# 游泳

## 蛙泳
小学的时候我就学会了蛙泳，并且能在泳池里不休息地一直游也不会累。很长一段时间里，我认为我是有一定游泳天赋的。直到上了大学，我遇到了很多比我游得好的人，我才知道山外有山。但这并不妨碍我对蛙泳很有自信，游泳也是我最擅长的运动了。游蛙泳就像呼吸一样简单。

## 自由泳
小时候虽然学过自由泳，但是我对自由泳一直没自信，也不会说自己会自由泳。到后来，干脆自己也觉得自己没学过了。高中毕业后，开始了漫长的自由泳自学时光。看的是B站梦觉教游泳（授业恩师了属于是），课程教得很好，但是还是无法突破脑子学会了身体不会的尴尬。中间断断续续丧失了兴趣，到本科毕业前夕，一次偶然的机会得到校游泳队朋友的指点，第一次有点觉得我学会自由泳了。最近两年断断续续地游，似乎是量变达到了质变。突然某天，我感觉一些东西改变了，我有自信说我会自由泳了。
