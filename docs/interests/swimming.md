# 游泳

## 蛙泳

小学时我就学会了蛙泳，能在泳池里不休息地一直游，也不会觉得累。很长一段时间里，我觉得自己多少有点游泳天赋。直到上了大学，遇见许多游得比我更好的人，我才明白山外有山。

但这并不妨碍我对蛙泳的自信，游泳仍是我最擅长的运动。游蛙泳对我来说，就像呼吸一样自然。

## 自由泳

小时候虽然学过自由泳，但我一直对它没信心，也从不敢说自己「会自由泳」。久而久之，连我自己都觉得，好像从没学过似的。

高中毕业后，我开始了漫长的自学。主要跟着 B 站「梦觉教游泳」学（授业恩师了属于是）。课程讲得很好，可我还是卡在那种尴尬里：脑子好像学会了，身体却跟不上。

中间断断续续，兴趣也淡过一阵。直到本科毕业前夕，校游泳队的朋友偶然指点了我几句，我第一次觉得：自由泳，我好像真的会了。

最近两年仍是断断续续地游。某个瞬间，量变似乎终于堆成了质变——我突然感到有什么东西不一样了。我终于有自信说：我会自由泳。
